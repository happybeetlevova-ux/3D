# Мастерская 3D — склад и юнит-экономика в одном приложении

Это замена двух приложений: «Склад 3D» и «Цена 3D». Ставится по тому же адресу,
что и склад, и при первом запуске само забирает данные из обоих.

## Если «Склад 3D» и «Цена 3D» уже стоят на телефоне

### Шаг 1. Страховка — сделайте копии (2 минуты)
1. Откройте «Склад 3D» → вкладка **Копия** → «Сохранить копию в файл».
2. Откройте «Цена 3D» → вкладка **Копия** → «Сохранить копию в файл».
Файлы окажутся в «Загрузках». Если что-то пойдёт не так, данные вернутся из них.

### Шаг 2. Замените файлы в репозитории `sklad`
1. На компьютере распакуйте `masterskaya.zip`.
2. github.com → ваш репозиторий **sklad** → **Add file → Upload files**.
3. Перетащите все файлы из архива. Одинаковые имена (index.html, sw.js…) заменятся — так и нужно.
4. Внизу **Commit changes**. Подождите 1–2 минуты.

### Шаг 3. Обновите приложение на телефоне
1. Включите интернет, откройте иконку «Склад 3D».
2. Закройте приложение полностью (смахните из списка открытых) и откройте ещё раз.
3. Сверху должно быть «Мастерская 3D» и сообщение «Данные перенесены».
   Если видите старый склад — подождите пару минут и повторите пункт 2.
   Имя под иконкой обновится само в течение суток.

Почему данные переносятся сами: оба старых приложения лежат на одном адресе
`ваше-имя.github.io`, поэтому телефон хранит их данные в общем месте, и новое
приложение их видит.

### Шаг 4. Уберите «Цена 3D»
1. Удалите иконку «Цена 3D» с телефона.
   **Если Android спросит «Удалить также данные сайта» — НЕ соглашайтесь**: данные
   у всех трёх приложений общие.
2. На GitHub репозиторий `cena` можно удалить: Settings → внизу Delete this repository.
   Или просто оставить — он не мешает.

Если автоперенос не сработал: «Ещё» → «Загрузить копию» → выберите по очереди обе
копии из шага 1 → «Перенести».

## Если старые приложения не ставили
Установите как новое: репозиторий `sklad` (или любое имя) → загрузить файлы →
Settings → Pages → main → Save → открыть адрес в Chrome → ⋮ → «Установить приложение».
Подробно — в инструкции к «Склад 3D».

## Как теперь всё связано
- **Пластик и детали имеют цену.** При «Пришло» введите, сколько заплатили, —
  приложение посчитает среднюю цену с учётом того, что уже лежит на складе.
  Подорожал пластик → себестоимость всех изделий из него обновится сама.
- **Состав изделия — один на всё.** По нему при «Напечатал» списываются пластик и детали,
  и по нему же считается себестоимость.
- **Расходы без учёта на складе** — для того, что не ведёте поштучно (маркировка, мелочь).
  Перенесённые из таблицы суммы (коробка, маркировка) лежат здесь. Когда заведёте коробки
  на складе с ценой и добавите в состав, удалите их из этого блока, чтобы не посчитать дважды.
- **Деньги на складе** — сколько стоят все остатки по себестоимости.
- **План** — сколько хотите продать в месяц → сколько допечатать (минус то, что уже есть),
  часы принтера, и таблица «каких материалов не хватает».

## Первые 15 минут
1. «Материалы» → откройте каждый пластик → «Изменить» → цена за кг. Детали — цена за штуку.
2. «Изделия» → откройте товар → «Состав» → «+ Пластик» → выберите катушку и граммы.
   Очистите поле «Пластик без привязки».
3. Укажите «Минимум на складе» у изделий, которые держите в наличии.
